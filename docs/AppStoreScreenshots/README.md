# App Store 제출용 스크린샷

2026년 9월 16일 iOS 26.0 시뮬레이터에서 실제 앱 화면을 촬영했다. 외부 악보나 개인정보를 포함하지 않는다.

| 대상 | 파일 | 크기 | 형식 |
| --- | --- | --- | --- |
| iPhone 6.9인치 | `iphone-6.9-home.jpg` | 1320 × 2868 | JPEG, 알파 없음 |
| iPad 13인치 | `ipad-13-home.jpg` | 2064 × 2752 | JPEG, 알파 없음 |

두 파일은 App Store Connect의 필수 기기군에 각각 한 장씩 바로 업로드할 수 있다. 더 풍부한 상품 페이지를 원하면 사용 권한이 있는 샘플 PDF로 분석 결과, 키 필터, 곡 뷰어 화면을 추가 촬영한다.

- [Apple 스크린샷 사양](https://developer.apple.com/help/app-store-connect/reference/app-information/screenshot-specifications)
- [스크린샷 업로드 안내](https://developer.apple.com/help/app-store-connect/manage-app-information/upload-app-previews-and-screenshots)
