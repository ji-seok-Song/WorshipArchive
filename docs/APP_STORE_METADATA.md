## 설명

찬양서랍은 여러 곡이 함께 들어 있는 찬양 악보 PDF를 곡 단위로 정리해 주는 iPhone·iPad 앱입니다.

PDF를 추가하면 내장 텍스트와 기기 내 문자 인식을 이용해 곡 제목, 페이지 범위, 키를 제안합니다. 결과를 직접 확인하고 수정한 뒤 저장할 수 있어 자동 인식이 완벽하지 않은 악보도 안전하게 정리할 수 있습니다.

주요 기능

• 여러 곡이 담긴 PDF를 한 번에 가져오기
• 곡 제목, 페이지 범위, 키 자동 제안
• 자동 분석 결과를 저장 전에 직접 수정
• 곡 제목과 원본 PDF 이름 검색
• 키별 라이브러리 필터
• 선택한 곡의 페이지만 바로 열기
• 곡 페이지만 별도 PDF로 만들어 공유
• 즐겨찾기와 마지막으로 본 페이지 기억
• 다른 PDF 앱의 공유 메뉴에서 바로 가져오기
• 기기에 먼저 저장하고 비공개 iCloud 공간으로 기기 간 동기화

악보 분석은 사용자의 기기에서 수행되며 광고, 사용자 추적 또는 제3자 분석 도구를 사용하지 않습니다. 찬양서랍은 악보 콘텐츠를 자체 제공하지 않으며 사용자가 직접 선택한 PDF만 처리합니다.

## App Review 메모

앱 자체 로그인은 필요하지 않습니다. iCloud에 로그인하지 않아도 로컬 저장 기능을 사용할 수 있습니다.

검토 방법:

1. 홈 또는 라이브러리의 PDF 추가 버튼으로 PDF를 선택합니다.
2. 분석이 끝나면 제안된 곡 제목, 키, 페이지 범위를 확인하고 저장합니다. 자동 분석 결과는 저장 전에 수정할 수 있습니다.
3. 라이브러리에서 곡을 누르면 원본 PDF 전체가 아니라 해당 곡의 페이지 범위만 표시됩니다.
4. 뷰어의 공유 버튼을 누르면 해당 곡의 페이지만 포함된 새 PDF가 생성됩니다.
5. 파일 앱 또는 Goodnotes 같은 앱의 공유 메뉴에서도 PDF를 찬양서랍으로 열 수 있습니다.
6. 두 기기가 같은 Apple 계정의 iCloud를 사용하는 경우 악보 정보와 PDF가 비공개 CloudKit 데이터베이스를 통해 동기화됩니다.

앱은 악보 콘텐츠를 자체 제공하거나 공개 배포하지 않습니다. 모든 PDF는 사용자가 직접 선택하며, 사용자는 가져오고 공유하는 콘텐츠에 필요한 권리를 보유해야 합니다. PDF 텍스트 분석과 Vision OCR은 기기 안에서 실행됩니다. 광고, 추적 및 제3자 분석 SDK는 포함되어 있지 않습니다.
