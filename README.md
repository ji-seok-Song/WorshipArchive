# 찬양서랍

여러 곡이 담긴 찬양 악보 PDF를 곡 단위로 정리하고, 곡 제목·원본 PDF 이름·키로 다시 찾을 수 있게 하는 iPhone·iPad 앱입니다.

## 개발 원칙

- 원본 PDF는 한 번만 보관하고 곡별 페이지 범위를 연결합니다.
- 곡별 페이지 범위는 별도 PDF로 만들어 공유할 수 있습니다.
- 자동 분석 결과는 사용자가 확인하고 수정한 뒤 저장합니다.
- 로컬에서 먼저 동작하고, 이후 CloudKit으로 기기 간 동기화합니다.
- 각 기능은 단독으로 빌드 가능한 작은 Git 커밋으로 남깁니다.

상세 구현 순서와 완료 조건은 [Docs/IMPLEMENTATION_PLAN.md](Docs/IMPLEMENTATION_PLAN.md)를 참고하세요.
