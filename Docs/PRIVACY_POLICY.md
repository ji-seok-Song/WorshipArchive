# 찬양서랍 개인정보처리방침

시행일: 2026년 8월 27일

찬양서랍은 사용자가 선택한 찬양 악보 PDF를 곡별로 정리하고 다시 찾을 수 있게 하는 앱입니다. 이 문서는 앱이 데이터를 처리하는 방식을 설명합니다.

> 배포 전 확인: 아래의 `[운영자명]`, `[연락 이메일]`을 실제 정보로 바꾸고 누구나 접속할 수 있는 웹페이지에 게시해야 합니다.

## 1. 처리하는 데이터

찬양서랍은 다음 정보를 앱 기능 제공에 사용합니다.

- 사용자가 직접 가져온 PDF 파일
- 곡 제목, 키, 페이지 범위, 원본 PDF 이름 등 사용자가 저장하거나 수정한 악보 정보
- 즐겨찾기와 마지막으로 본 페이지 등 앱 사용 상태

앱에는 광고, 사용자 추적 또는 제3자 분석 SDK가 포함되어 있지 않습니다.

## 2. 처리 목적과 방식

- PDF의 문자 인식과 곡 구분은 Apple Vision 및 PDFKit을 이용해 사용자의 기기에서 처리합니다.
- 데이터는 먼저 사용자의 기기에 저장됩니다.
- 사용자가 iCloud에 로그인했고 iCloud를 사용할 수 있으면 악보 정보와 PDF가 사용자의 비공개 iCloud 저장 공간에 동기화될 수 있습니다. 이 동기화에는 Apple의 CloudKit 서비스가 사용됩니다.
- 운영자는 별도의 서버로 사용자의 악보, 검색어 또는 이용 기록을 전송하거나 열람하지 않습니다.

## 3. 외부 공유

사용자가 공유 기능을 직접 실행하면 선택한 곡의 PDF가 iOS/iPadOS 공유 시트를 통해 사용자가 고른 다른 앱이나 사람에게 전달됩니다. 전달 이후의 처리는 해당 서비스의 개인정보처리방침을 따릅니다.

## 4. 보관과 삭제

- 사용자는 앱에서 저장한 곡을 삭제할 수 있습니다.
- 앱을 삭제하면 기기에 저장된 앱 데이터가 제거됩니다.
- iCloud에 동기화된 데이터는 사용자의 Apple 계정과 iCloud 설정에 따라 보관될 수 있으며, 사용자는 기기의 iCloud 저장 공간 설정에서 해당 앱 데이터를 관리할 수 있습니다.

## 5. 아동의 개인정보

찬양서랍은 아동을 포함한 사용자의 개인정보를 별도로 요청하거나 광고 목적으로 수집하지 않습니다.

## 6. 방침 변경

앱의 데이터 처리 방식이 바뀌면 이 문서를 갱신하고 시행일을 변경합니다.
